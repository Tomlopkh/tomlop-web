Goal vs System

គោលដៅ និង ប្រព័ន្ធ

អានប្រហែល ២ នាទីAbout 2 min read

មនុស្សភាគច្រើនតែងតែដាក់គោលដៅធំៗក្នុងជីវិត ប៉ុន្តែមិនមែនគ្រប់គ្នាសុទ្ធតែអាចទៅដល់គោលដៅនោះទេ។ ហេតុអ្វី? ពីព្រោះគោលដៅ (Goal) គ្រាន់តែប្រាប់អ្នកថាអ្នកចង់ទៅណា តែប្រព័ន្ធ (System) ទើបជាអ្នកនាំអ្នកទៅដល់ទីនោះ។

អ្នកឈ្នះនិងអ្នកចាញ់ សុទ្ធតែមានគោលដៅដូចគ្នា តែអ្វីដែលខុសគ្នាគឺប្រព័ន្ធដែលពួកគេប្រើប្រាស់ប្រចាំថ្ងៃ។

ហេតុអ្វីសំខាន់?

  • គោលដៅកំណត់ទិសដៅ ប៉ុន្តែប្រព័ន្ធជាអ្នកបង្កើតលទ្ធផលជាក់ស្តែង។
  • បើអ្នកមានតែគោលដៅ តែគ្មានប្រព័ន្ធ អ្នកនឹងងាយបាក់ទឹកចិត្តពេលជួបឧបសគ្គ។
  • ប្រព័ន្ធល្អធ្វើឱ្យភាពជោគជ័យក្លាយជារឿងស្វ័យប្រវត្តិ មិនមែនកើតឡើងដោយចៃដន្យ។

ឧទាហរណ៍

  • គោលដៅ: ចង់បានរាងស្អាត។ ប្រព័ន្ធ: ហាត់ប្រាណ ៣ ថ្ងៃក្នុងមួយសប្តាហ៍ និងញ៉ាំអាហារល្អជារៀងរាល់ថ្ងៃ។
  • គោលដៅ: ចង់សរសេរសៀវភៅមួយក្បាល។ ប្រព័ន្ធ: សរសេរ ៥០០ ពាក្យរៀងរាល់ព្រឹកម៉ោង ៦។

អ្វីយកទៅប្រើ

  • **ផ្តោតលើទម្លាប់ប្រចាំថ្ងៃ៖** កុំចំណាយពេលគិតតែពីគោលដៅពេក ចូរផ្ដោតលើការកសាងប្រព័ន្ធទម្លាប់ប្រចាំថ្ងៃឱ្យរឹងមាំ។
  • **បំបែកជាសកម្មភាពជាក់ស្តែង៖** បំបែកគោលដៅធំៗឱ្យទៅជាសកម្មភាពតូចៗដែលអាចអនុវត្តបានជារៀងរាល់ថ្ងៃ។
  • **ស្រឡាញ់ដំណើរការនៃការធ្វើ៖** រៀនសប្បាយចិត្តនឹងការអនុវត្តជាក់ស្តែង មិនមែនគ្រាន់តែរង់ចាំក្តីសុខពីលទ្ធផលចុងក្រោយឡើយ។

ចំណុចចាំ

គោលដៅប្រាប់ពីគោលដៅរបស់អ្នក តែប្រព័ន្ធប្រាប់ពីអនាគតរបស់អ្នក។
