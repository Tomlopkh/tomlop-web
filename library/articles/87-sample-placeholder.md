# Sample Placeholder / ឧទាហរណ៍គំរូ

នេះជាអត្ថបទគំរូ ដែលបង្ហាញពីទម្រង់ត្រឹមត្រូវសម្រាប់មាតិកាដែលផ្ញើតាមបណ្ដាញ។
វាមិនមែនជាមាតិកាពិតទេ ហើយគួរតែត្រូវបានជំនួស មុនពេលបើកមុខងារនេះជាផ្លូវការ។

## ទម្រង់ដែលកម្មវិធីអាន

- បន្ទាត់ចំណងជើងត្រូវចាប់ផ្ដើមដោយ `#` ហើយបំបែកភាសាអង់គ្លេស និងខ្មែរដោយ ` / `។
- បន្ទាត់ដែលចាប់ផ្ដើមដោយ `##` ក្លាយជាចំណងជើងផ្នែក។
- បន្ទាត់ដែលចាប់ផ្ដើមដោយ `-` ក្លាយជាចំណុចរាយ។
- បន្ទាត់ធម្មតាផ្សេងទៀត ក្លាយជាកថាខណ្ឌ។

## ហេតុអ្វីទម្រង់នេះ

ទម្រង់នេះដូចគ្នាបេះបិទនឹងឯកសារ Markdown ចំនួន ៨៦ ដែលមានស្រាប់ក្នុងកម្មវិធី។
ដូច្នេះមាតិកាដែលទាញយកពីបណ្ដាញ ប្រើកម្មវិធីអានតែមួយ ដោយមិនចាំបាច់កែកូដឡើយ។
