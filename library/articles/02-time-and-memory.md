# Time and Memory / ពេលវេលា និងការចងចាំ

ពេលវេលាដើរទៅមុខជានិច្ចដូចខ្សែទឹកហូរ ប៉ុន្តែការចងចាំរបស់យើងបែរជាលោតចុះលោតឡើង ជួនកាលច្បាស់ ជួនកាលព្រិលៗ។ 
អតីតកាលនៅក្នុងខួរក្បាលអ្នក មិនមែនជាវីដេអូកាមេរ៉ាសុវត្ថិភាពទេ វាជារឿងនិទានដែលអារម្មណ៍អ្នកជាអ្នកតែង។

## ហេតុអ្វីសំខាន់?

- ការចងចាំរបស់យើងតែងតែត្រូវកែច្នៃ (edit) រាល់ពេលដែលយើងនឹកឃើញវា។
- អារម្មណ៍បច្ចុប្បន្នអាចលាបពណ៌លើអតីតកាល។ ពេលអ្នកសប្បាយចិត្ត រឿងអតីតកាលមើលទៅល្អ ពេលអ្នកសោកសៅ រឿងនោះមើលទៅអាក្រក់។
- បើយើងចាប់ជាប់នឹងការចងចាំឈឺចាប់ខ្លាំងពេក យើងនឹងបាត់បង់ថាមពលសាងអនាគត។

## ឧទាហរណ៍

- អ្នកអាចចាំថាការប្រឡងបាក់ឌុបគឺតានតឹងខ្លាំង ប៉ុន្តែការពិតអ្នកក៏មានពេលសើចសប្បាយជាមួយមិត្តភក្តិដែរ គ្រាន់តែខួរក្បាលអ្នកចងចាំតែភាពភ័យខ្លាច។
- បទពិសោធន៍បរាជ័យមួយដង អាចធ្វើឱ្យអ្នកខ្លាចរអាក្នុងការចាប់ផ្ដើមរឿងថ្មី ព្រោះការចងចាំប្រាប់អ្នកថា "អ្នកនឹងបរាជ័យទៀត"។

## អ្វីយកទៅប្រើ

- **កត់ត្រាទុក៖** សរសេរកំណត់ហេតុ (journaling) ដើម្បីទុកជាភស្តុតាងនៃការពិត កុំពឹងតែលើខួរក្បាល។
- **កុំឱ្យអតីតកាលធ្វើមេបញ្ជាការ៖** អ្វីដែលធ្លាប់កើតឡើង មិនមែនមានន័យថាវានឹងកើតឡើងម្តងទៀតទេ។
- **ផ្ដោតលើអ្វីដែលអាចសាងបាន៖** អនាគតគឺជារឿងដែលអ្នកអាចគ្រប់គ្រងបាននៅថ្ងៃនេះ។

## ចំណុចចាំ

អតីតកាលជាមេរៀន មិនមែនជាគុកឃុំឃាំងយើងនោះទេ។
