# Learning & Memory / ការរៀន និងការចងចាំ

ការអានសៀវភៅចប់មួយក្បាល មិនមែនមានន័យថាអ្នកចេះនោះទេ វាគ្រាន់តែជាការចងចាំមួយភ្លែត។ 
ការរៀនសូត្រពិតប្រាកដ គឺការប្រែព័ត៌មានឱ្យទៅជា "សមត្ថភាព"។

## ហេតុអ្វីសំខាន់?

- ការចងចាំ (Memory) នឹងត្រូវហើរវង្វេងតាមខ្យល់ ប្រសិនបើអ្នកមិនយកវាទៅប្រើ។
- ការយល់ដឹងស៊ីជម្រៅ (Deep Learning) កើតឡើងនៅពេលដែលអ្នកអាចយកអ្វីដែលរៀន ទៅដោះស្រាយបញ្ហាក្នុងជីវិតពិត។
- ការចំណាយពេលអានច្រើនម៉ោងជាប់គ្នា មិនមានប្រសិទ្ធភាពស្មើនឹងការអានតិចៗ តែមានការអនុវត្ត។

## ឧទាហរណ៍

- អ្នកអានសៀវភៅពីរបៀបហែលទឹកចប់ ៥ ក្បាល តែបើមិនព្រមចុះទឹក អ្នកនៅតែមិនចេះហែលដដែល។
- អ្នករៀនពាក្យថ្មីថ្ងៃនេះ ហើយរំលឹកវានៅថ្ងៃស្អែក សប្តាហ៍ក្រោយ និងខែក្រោយ នោះវានឹងក្លាយជារបស់អ្នកមួយជីវិត។

## អ្វីយកទៅប្រើ

- **រៀនបណ្តើរ ធ្វើបណ្តើរ៖** កុំរង់ចាំទាល់តែចេះច្បាស់ទើបធ្វើ ត្រូវសាកល្បងអនុវត្តភ្លាមៗទោះខុសក៏ដោយ។
- **ពន្យល់អ្នកដទៃ (Feynman Technique)៖** បើអ្នកអាចពន្យល់រឿងពិបាកឱ្យក្មេងអាយុ ១០ ឆ្នាំយល់បាន មានន័យថាអ្នកយល់វាច្បាស់ហើយ។
- **រំលឹកឡើងវិញ (Spaced Repetition)៖** កុំរៀនមួយដងចោល រំលឹកមេរៀននោះឡើងវិញជាប្រចាំ ដើម្បីឱ្យខួរក្បាលកត់ត្រាវាចូលក្នុងការចងចាំរយៈពេលវែង។

## ចំណុចចាំ

ចំណេះដឹងគឺជាគ្រាប់ពូជ រីឯការអនុវត្តគឺជាទឹក។ បើគ្មានទឹក គ្រាប់ពូជក៏មិនអាចដុះបានដែរ។
